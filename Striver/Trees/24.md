# Time Complexity Analysis

## Step 1: Height Calculations

For every recursive call:


Each height traversal goes only downward.

For a complete binary tree:

* Height = `log N`

So:

```text
findeLeftHeight  -> O(log N)
findRightHeight -> O(log N)
```

Combined:

```text
O(log N)
```

In a complete binary tree:

* One subtree will definitely be perfect
