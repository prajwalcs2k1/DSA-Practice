This is one of the most elegant recursive tree problems because it combines:

* DFS
* Backtracking
* Distance propagation upward
* Opposite subtree traversal

You should understand this deeply because it appears in many interview variations.

---

# 🎯 Problem

Find all nodes at distance `k` from a given `target`.

Distance can be:

* downward
* upward
* sideways via ancestor

---

# 🔥 BIG IDEA OF THIS SOLUTION

The recursive function does TWO jobs simultaneously:

---

## Job 1:

Find the target node.

---

## Job 2:

While recursion unwinds upward:

* calculate distances from target
* explore opposite subtrees

---

# FULL CODE

```cpp id="1xv1uo"
void findDown(Node* root, int k, vector<int>& res) {
    if (!root || k < 0) return;

    if (k == 0) {
        res.push_back(root->data);
        return;
    }

    findDown(root->left, k - 1, res);
    findDown(root->right, k - 1, res);
}

int solve(Node* root, Node* target, int k, vector<int>& res) {

    if (!root) return -1;

    if (root == target) {
        findDown(root, k, res);
        return 0;
    }

    int left = solve(root->left, target, k, res);

    if (left != -1) {

        if (left + 1 == k)
            res.push_back(root->data);

        else
            findDown(root->right, k - left - 2, res);

        return left + 1;
    }

    int right = solve(root->right, target, k, res);

    if (right != -1) {

        if (right + 1 == k)
            res.push_back(root->data);

        else
            findDown(root->left, k - right - 2, res);

        return right + 1;
    }

    return -1;
}
```

# PART 1 → `findDown()`

---

```cpp id="m1g1s0"

```

Purpose:

> Find all nodes exactly `k` distance BELOW current node.

This is simple DFS.

Stop conditions.

### Cases:

* distance exceeded

---


Store answer.

# PART 2 → `solve()`

THIS is the real magic.

---

# FUNCTION PURPOSE

```cpp id="bdk2fw"
int solve(...)
```

This function RETURNS:

```text id="0m3m9i"
distance from current node to target
```

If target not found:

```text id="6v71mu"
return -1
```

---

# 🔥 MOST IMPORTANT CONCEPT

This function is NOT just searching.

It is:

* searching downward
* while sending distance information upward

This is BACKTRACKING.

---

# LINE

```cpp id="ktj0uz"
if (!root) return -1;
```

Target not found.

---

# LINE

```cpp id="02mng0"
if (root == target)
```

We found target.

---

# LINE

```cpp id="j1tr4m"
findDown(root, k, res);
```

Find all nodes below target at distance k.

Example:

```text id="b5v73o"
target
   |
 descendants
```

---

# LINE

```cpp id="0cn1mq"
return 0;
```

Meaning:

> distance(target, target) = 0

This value travels upward through recursion.

---

# 🔥 NOW THE BACKTRACKING STARTS

---

Suppose tree:

```text id="tw0zic"
          1
         / \
        2   3
       /
      4
```

Target = 4

---

We recurse:

```text id="4z6c7w"
1 -> 2 -> 4
```

At 4:

```cpp id="6o5kxa"
return 0;
```

---

At node 2:

```cpp id="v8e6yf"
int left = solve(root->left...)
```

left becomes:

```text id="y3dch4"
0
```

Meaning:

```text id="e6b4ei"
distance(2->4) through left child = 1
```

---

# LINE

```cpp id="s5xjgm"
if (left != -1)
```

Meaning:

> target exists in left subtree

---

# LINE

```cpp id="0gk34m"
if (left + 1 == k)
```

Why `+1`?

Because:

* left = distance from LEFT CHILD to target
* current root is one edge above left child

So:

```text id="5omf8d"
distance(root,target) = left + 1
```

---

# Example

At node 2:

```text id="b9h0x8"
left = 0
```

Then:

```text id="x0xq1l"
left + 1 = 1
```

Correct:

```text id="gtj0ff"
distance(2,4)=1
```

---

# LINE

```cpp id="zw2x7w"
res.push_back(root->data);
```

If current node itself is exactly distance k away.

---

# ELSE PART

```cpp id="g61lpk"
else
    findDown(root->right, k - left - 2, res);
```

This is the hardest line.

---

# WHAT IS HAPPENING HERE?

Target is in LEFT subtree.

We now search RIGHT subtree.

---

# WHY?

Because nodes at distance k may exist there.

Example:

```text id="dh9fxh"
          1
         / \
        2   3
       /
      4
```

Target = 4
K = 3

Answer:

```text id="j6gzyx"
3
```

Path:

```text id="g5sm3n"
4 -> 2 -> 1 -> 3
```

---

# DISTANCE ACCOUNTING

At root 1:

```text id="d2lxw4"
left = 1
```

Meaning:

```text id="5b0zhq"
distance(2->4)=1
```

Current node 1 is:

```text id="khjlwm"
left+1 = 2
```

away from target.

---

Now to enter RIGHT subtree:

Need another edge:

```text id="l40fw0"
1 -> 3
```

So total consumed:

```text id="zkd1sa"
left + 2
```

---

Remaining distance:

```text id="i2dcg8"
k - left - 2
```

---

# WHY EXACTLY 2?

Because:

* one edge upward to current root
* one edge downward into opposite subtree

---

# LINE

```cpp id="b66z5i"
return left + 1;
```

VERY IMPORTANT.

We tell parent:

> "I am `left+1` away from target"

This propagates distance upward.

---

# RIGHT SIDE

Symmetric logic.

---

```cpp id="mx5z1y"
int right = solve(root->right...)
```

Target found in right subtree.

---

Then:

* maybe current node is answer
* maybe left subtree contains answers

---

# FINAL RETURN

```cpp id="9qjlwm"
return -1;
```

Target absent from both sides.

# 🔥 TRUE BEAUTY OF THIS SOLUTION

It avoids:

* parent map
* extra BFS
* visited array

Only recursion stack.

---

# Time Complexity

Each node visited at most once.

```text id="g9o9c8"
O(N)
```

---

# Space Complexity

Recursion stack:

```text id="5d0xwz"
O(H)
```

where H = height.

---

# FINAL MENTAL MODEL

The recursive function is doing:

```text id="0j8qlz"
1. Find target
2. While returning upward:
      calculate distance
3. Explore opposite subtree
```
