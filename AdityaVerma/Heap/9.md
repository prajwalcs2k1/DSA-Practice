````md
# Time Complexity (T.C.)

Let:
- `N` = size of the array
- `M` = number of unique elements
````

Traverses all elements once.

Time Complexity:

O(N)

---

## 2. Heap Insertions

We insert only unique elements into the heap.

Number of insertions = `M`

Each insertion into priority queue takes:

O(log M)

So total heap insertion complexity:

O(M log M)

---

## 3. Building Final Answer

```cpp
while(!pq.empty())
```

Every array element is pushed once into the answer vector.

Complexity:

O(N)

---

# Overall Time Complexity

```text
O(N + M log M)
```

Worst Case:

* when all elements are unique
* `M = N`

Then:

```text
O(N log N)
```

---

# Space Complexity (S.C.)

## 1. unordered_map

Stores frequency of unique elements:

```text
O(M)
```

---

## 2. priority_queue

Stores unique elements:

```text
O(M)
```

---

## 3. Output Vector

Stores all array elements:

```text
O(N)
```

---

# Overall Space Complexity

```text
O(N + M)
```

Worst Case:

* `M = N`

So:

```text
O(N)
```
