People often mix up **heapify** and **build heap**, but they are different operations.

---

# 1. Heapify

Heapify means:

> Fix the heap property at ONE specific node/subtree.

It assumes:

* child subtrees are already heaps
* only current node may violate heap property

---

## Example

Suppose:

```text id="89r6e9"
        4
      /   \
     10    3
```

This is not a Max Heap because:

* parent 4 < child 10

Calling:

```cpp id="wvwfzn"
heapify(arr, n, 0);
```

will fix ONLY this subtree.

Result:

```text id="p3q48r"
       10
      /   \
      4    3
```

Now subtree rooted at index 0 becomes a valid heap.

---

# Heapify Complexity

Worst case:

O(\log N)

because node may travel from root to leaf.

---

# 2. Build Heap

Build Heap means:

> Convert an entire arbitrary array into a valid heap.

It repeatedly uses `heapify()` internally.

---

## Build Heap Process

Starting from:

* last non-leaf node
* move upward toward root

```cpp id="r6yn6g"
for(int i=(n/2)-1; i>=0; i--){
    heapify(arr, n, i);
}
```

---

# Example

Input array:

```text id="7nq3qk"
4 10 3 5 1
```

Not a heap initially.

After build heap:

```text id="tuttns"
10 5 3 4 1
```

Entire array becomes a valid Max Heap.

---

# Key Difference

| Heapify                 | Build Heap                     |
| ----------------------- | ------------------------------ |
| Fixes one subtree       | Fixes entire array             |
| Operates on one node    | Operates on all non-leaf nodes |
| Used internally         | Complete heap construction     |
| Complexity = `O(log N)` | Complexity = `O(N)`            |

---

# Relationship Between Them

Think of it like this:

```text id="tk4kkh"
Build Heap = Multiple Heapify Calls
```

---

# Analogy

Imagine:

* `heapify()` = fixing one broken room
* `buildHeap()` = fixing the whole building room-by-room

---

# Important Interview Point

When interviewer says:

> "Implement heapify"

they usually mean:

* heapify-down for one node

When they say:

> "Build heap from array"

they mean:

* repeatedly call heapify bottom-up

---

# Visual Flow

```text id="ytj8ef"
Random Array
     ↓
Build Heap

     ↓

```
