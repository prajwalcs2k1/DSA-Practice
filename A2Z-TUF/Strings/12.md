# 📌 Count Substrings with Exactly **K Distinct Characters** (C++)

## 🔹 Problem Statement

Given a string `s` and an integer `k`, count the number of **substrings** of `s` that contain **exactly `k` distinct characters**.

---

## 🔹 Approach Overview (Key Idea)

Instead of directly counting substrings with **exactly `k` distinct characters**, we use this powerful identity:

> **Substrings with exactly `k` distinct characters**
> = **Substrings with at most `k` distinct characters**
> − **Substrings with at most `k-1` distinct characters**

This converts a **hard problem** into two **easy sliding-window problems**.

---

## 🔹 Why Direct Counting is Hard 🤯

In a sliding window:

* When the window has `k` distinct characters,
* **Not all substrings inside that window have exactly `k` distinct characters**

Some substrings may drop to `k-1`, `k-2`, etc.

So a simple condition like:

```cpp
if (mp.size() == k) res++;
```

❌ does **not** work correctly.

---

## 🔹 Why the Subtraction Trick Works ✅

Let’s define:

* `atMost(k)` = number of substrings with **≤ k distinct characters**
* `atMost(k-1)` = number of substrings with **≤ k-1 distinct characters**

### Observation:

* `atMost(k)` includes:

  * substrings with **1, 2, ..., k distinct characters**
* `atMost(k-1)` includes:

  * substrings with **1, 2, ..., k-1 distinct characters**

### When we subtract:

```
atMost(k) - atMost(k-1)
```

All substrings with fewer than `k` distinct characters cancel out.

✔ What remains = **substrings with exactly `k` distinct characters**

This is why subtraction is **necessary and correct**.

---

## 🔹 Understanding the `atMost()` Function

### Function Goal

Count all substrings that contain **at most `k` distinct characters**.

### Technique Used

➡ **Sliding Window + Frequency Map**

---

## 🔹 How Sliding Window Works Here 🪟

We maintain a window `[i … j]` such that:

* The number of distinct characters in the window is **≤ k**

### Variables:

* `i` → left pointer
* `j` → right pointer
* `mp` → frequency map of characters in the window
* `res` → total number of valid substrings

---

## 🔹 Step-by-Step Logic of `atMost()`

```cpp
mp[s[j]]++;
```

➡ Include the new character into the window.

---

```cpp
while (mp.size() > k) {
    mp[s[i]]--;
    if (mp[s[i]] == 0) mp.erase(s[i]);
    i++;
}
```

➡ Shrink the window **until it becomes valid again**
(≤ `k` distinct characters)

This ensures the window is **always valid**.

---

```cpp
res += (j - i + 1);
```

### 🔥 Most Important Line

Why does this work?

At index `j`, all substrings ending at `j` and starting from:

```
i, i+1, i+2, ..., j
```

are **valid substrings** (they all have ≤ `k` distinct characters).

Number of such substrings:

```
(j - i + 1)
```

So we add all of them in **O(1)** time.

---

## 🔹 Time & Space Complexity

### Time Complexity

* Each character enters and leaves the window **once**
* Overall: **O(n)**

### Space Complexity

* Frequency map stores at most `k` characters
* **O(k)**

---

## 🔹 Example Walkthrough

For:

```
s = "pqpqs"
k = 2
```

* `atMost(2)` = 12
* `atMost(1)` = 5

```
Exactly 2 = 12 - 5 = 7
```

✔ Correct answer.

---

## 🔹 Key Takeaways 🧠

* Sliding window works **only when the window is always valid**
* `res += (j - i + 1)` counts **all substrings ending at `j`**
* Exact `k` is hard → convert to **atMost subtraction**
* Frequency count (`++ / --`) is mandatory to handle duplicates

---

## 🔹 When to Use This Pattern

Use this approach for problems like:

* Substrings with exactly `k` distinct characters
* Longest substring with at most `k` distinct
* Count of subarrays with at most `k` unique elements
