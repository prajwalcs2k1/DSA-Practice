### 🔹 1. Avoid `unordered_map` overhead

Since Roman numerals have only **7 fixed characters**, you can avoid hashing:

```cpp
int value(char c) {
    switch (c) {
        case 'I': return 1;
        case 'V': return 5;
        case 'X': return 10;
        case 'L': return 50;
        case 'C': return 100;
        case 'D': return 500;
        case 'M': return 1000;
    }
    return 0;
}
```

This is slightly faster and very common in interviews.
