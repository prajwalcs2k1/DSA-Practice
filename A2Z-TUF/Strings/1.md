# Remove Outermost Parentheses – C++

## 📌 Problem Statement

Given a **valid parentheses string**, remove the **outermost parentheses** of every primitive substring and return the resulting string.

A **primitive parentheses string** is a non-empty valid parentheses string that cannot be split into two non-empty valid parentheses strings.

### Example

| Input                | Output            |
| -------------------- | ----------------- |
| `(()())(())`         | `()()()`          |
| `(()())(())(()(()))` | `()()()()(())`    |
| `()()`               | `` (empty string) |

---

## 🧠 Key Idea Behind the Solution

Instead of using a **stack**, this solution uses a **counter-based approach** to track the nesting level of parentheses.

* `openParenth` keeps track of how deeply nested we are.
* The **outermost parentheses** are:

  * `'('` when `openParenth == 0`
  * `')'` when `openParenth == 1`
* These outermost parentheses are **skipped**, while all inner parentheses are included in the result.

This makes the solution:

* ✅ Efficient
* ✅ Easy to understand
* ✅ Stack-free

---

## ⚙️ Algorithm Explanation (Step-by-Step)

1. Initialize an empty result string `str`.
2. Initialize a counter `openParenth = 0`.
3. Traverse the input string character by character:

### When encountering `'('`

* If `openParenth > 0`, it means this is **not an outermost '('**, so include it in the result.
* Increment `openParenth`.

### When encountering `')'`

* Decrement `openParenth`.
* If `openParenth > 0` *before decrementing*, this is **not an outermost ')'**, so include it in the result.

4. Continue until the entire string is processed.
5. Return the resulting string.

---
### 🔍 Why This Works

* `openParenth` tracks nesting depth.
* Parentheses are only added when they are **inside** another pair.
* The outermost layer is effectively removed.

---

## ⏱️ Time & Space Complexity

* **Time Complexity:** `O(n)`

  * Each character is processed once

* **Space Complexity:** `O(n)`

  * For storing the result string
