# 📌 Missing Number Using Binary Search (C++)

## Problem Statement

Given an array `nums` containing **n distinct numbers** taken from the range **[0, n]**, exactly **one number is missing**.
The task is to find that missing number.

---

## ⚠️ Important Constraint for Binary Search

Binary Search **only works on sorted data**.

So before applying Binary Search:

1. **Sort the array**
2. Exploit the relationship between **index and value**

---

## 🧠 Key Observation (Core Idea)

After sorting the array:

* **Before the missing number**

  ```
  arr[i] == i
  ```

* **At and after the missing number**

  ```
  arr[i] > i
  ```

Why this happens:

* Since one number is missing, all numbers **after it shift right by 1**
* This creates a **monotonic condition**, perfect for Binary Search

---

## 🔍 Binary Search Strategy

We want to find the **first index `i` where**:

```
arr[i] > i
```

That index `i` is the **missing number**.

---

## 🧩 Binary Search Helper Function

```cpp
int usingBSHelper(vector<int> &arr, int low, int high){
    while(low < high){
        int mid = low + (high - low) / 2;

        if(arr[mid] > mid)
            high = mid;
        else
            low = mid + 1;
    }
    return low;
}
```

---

## 🔁 Step-by-Step Logic

| Condition         | Meaning                         | Action       |
| ----------------- | ------------------------------- | ------------ |
| `arr[mid] == mid` | No missing number yet           | Search right |
| `arr[mid] > mid`  | Missing number at or before mid | Search left  |

---

## 🧪 Example Walkthrough

**Input:**

```
arr = [3, 0, 1]
```

After sorting:

```
arr = [0, 1, 3]
index:  0  1  2
```

At index `2`:

```
arr[2] = 3 > 2
```

👉 Missing number = **2**

---

## 🧠 Why `return low` Works

* Loop ends when `low == high`
* This index is the **first mismatch**
* That mismatch index is the **missing number**

Returning `low` or `high` both work because:

```
low == high at termination
```

---

## ⏱ Time & Space Complexity

| Operation     | Complexity |
| ------------- | ---------- |
| Sorting       | O(n log n) |
| Binary Search | O(log n)   |
| Extra Space   | O(1)       |

⚠️ **Not optimal** compared to Math/XOR solutions, but excellent for learning **binary search on conditions**.

---

## 🧠 When to Use This Pattern Again

Use this technique when:

* Array is **sorted**
* There is a **value ↔ index relationship**
* You’re finding the **first position where a condition breaks**

This pattern appears frequently in:

* Competitive Programming
* System Design interview problems
* Advanced LeetCode binary search questions

---

## ✅ Final Takeaway (Must Remember)

> **In a sorted array of distinct numbers from [0, n],
> the missing number is the first index where `arr[i] > i`.**
