## Problem Reminder

We want:

> **Longest** subarray with sum = `K`

Using prefix sum:

```
prefixSum[i] - prefixSum[j] = K
→ subarray (j+1 … i) has sum K
→ length = i - j
```

So to **maximize length**, we want **j as small as possible**
➡️ that means **earliest occurrence** of `(prefixSum - K)`

---

## Example That BREAKS If You Overwrite

### Input

```
arr = [1, 2, -2, 2, -2, 2]
K = 2
```

---

## Step-by-step Prefix Sum

| Index | arr[i] | prefixSum |
| ----- | ------ | --------- |
| 0     | 1      | 1         |
| 1     | 2      | 3         |
| 2     | -2     | 1         |
| 3     | 2      | 3         |
| 4     | -2     | 1         |
| 5     | 2      | 3         |

---

## CASE 1️⃣: ❌ WRONG — You overwrite prefix sums

```cpp
mp[prefixSum] = i;   // always overwrite
```

### What happens?

Prefix sum `1` occurs at indices:

```
0, 2, 4
```

But the map stores:

```
mp[1] = 4   ❌ (last occurrence)
```

Now at index `5`:

```
prefixSum = 3
prefixSum - K = 1
```

Length computed:

```
5 - 4 = 1   ❌
```

You miss the longer subarray!

---

## CASE 2️⃣: ✅ CORRECT — Store first occurrence only

```cpp
if(mp.find(prefixSum) == mp.end())
    mp[prefixSum] = i;
```

### Map now contains:

```
mp[1] = 0   ✅ earliest
mp[3] = 1
```

At index `5`:

```
prefixSum = 3
prefixSum - K = 1
```

Length:

```
5 - 0 = 5   ✅ CORRECT
```

### Subarray:

```
[2, -2, 2, -2, 2] → sum = 2
```

---

## Why This Works (Key Insight)

> **Earlier index → longer subarray**

If:

```
prefixSum[j1] = prefixSum[j2] = X
and j1 < j2
```

Then for any `i`:

```
i - j1 > i - j2
```

So:
✔️ Always keep the **earliest index**

---

## One-Line Rule to Remember 🧠

> **For longest subarray problems using prefix sum,
> always store the FIRST occurrence of a prefix sum.**
