## Correct Way to Think About This Problem

A **sorted + rotated array (non-decreasing, duplicates allowed)** has a very important property:

> There can be **at most one “drop”** in the array
> where `nums[i] > nums[i+1]`

### Why?

* In a sorted array → no drops
* In a rotated sorted array → exactly **one drop** (the rotation point)
* More than one drop → not a sorted array

---

## Key Insight

Count how many times:

```
nums[i] > nums[(i+1) % n]

OR

nums[i] < nums[(i-1+n) % n]
```

If this count is **≤ 1**, return `true`
Otherwise, return `false`

---

## Example Walkthrough

### Example 1

```
[3,4,5,1,2]
drops:
5 > 1   → 1 drop ✅
```

✔️ Valid

---

### Example 2

```
[2,1,3,4]
drops:
2 > 1   → 1 drop
1 > 3   → no
3 > 4   → no
4 > 2   → another drop ❌
```

❌ Invalid

---

## Mental Model to Remember

> **“A rotated sorted array breaks sorted order at most once.”**
