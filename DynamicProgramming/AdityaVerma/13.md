A **supersequence** of a string is simply another string that **contains the original string as a subsequence**.

✅ **Definition:**
If you have a string **A**, then a string **B** is called a **supersequence of A** if all characters of **A** appear in **B** in the **same relative order** (not necessarily contiguously).

### Example

Let
A = `"abc"`

Then all of the following are **supersequences of A**:

* `"abc"` (same string)
* `"axbyc"`
* `"a1b2c3"`
* `"zabcx"`

Because **a → b → c appear in order**.

But these are **not** supersequences:

* `"acb"` (order changed)
* `"ab"` (missing `c`)

---

### Related Concept: Shortest Common Supersequence (SCS)

For two strings **A and B**, their **Shortest Common Supersequence (SCS)** is the shortest string that is a supersequence of both.

Example:
A = `"ab"`
B = `"bc"`
SCS = `"abc"`

Because `"abc"` contains both `"ab"` and `"bc"` as subsequences.

---

### Quick Summary

| Term          | Meaning                                                            |
| ------------- | ------------------------------------------------------------------ |
| Subsequence   | You can remove characters but keep order                           |
| Supersequence | You can add characters but must keep order                         |
| SCS           | Minimum-length string that includes both sequences as subsequences |
